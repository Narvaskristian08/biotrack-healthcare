# BioTrack  
**A Smart IoT Vital Sensing and AI Health Advisory Platform with Blockchain-Verified Patient Records**

## Project Overview

**BioTrack** is a cross-platform mobile and web healthcare platform that integrates **smartphone-based IoT vital sensing**, **AI-powered health advisory**, and **blockchain-secured medical records**. The system enables accessible, preventive digital healthcare without requiring external medical hardware.

The platform supports **Sustainable Development Goal (SDG) 3: Good Health and Well-Being** by democratizing access to essential health monitoring and advisory tools using devices people already own—smartphones.

## Technical Description

Access to reliable and timely healthcare remains limited in many communities, particularly those with inadequate medical facilities. Early detection of health abnormalities—such as irregular heart rate, fatigue, or abnormal movement—can significantly reduce health risks.

Most digital health systems rely on **specialized or expensive hardware**, limiting accessibility.

**BioTrack addresses this gap** by creating a **scalable, secure, and low-cost digital healthcare ecosystem** that integrates **mobile IoT vital sensing, AI-powered health advisory, and blockchain-secured patient records**.

The system collects and analyzes essential health indicators using smartphone sensors:

### Mobile IoT Sensing
- Camera + flashlight for **PPG-based heart rate detection**
- Accelerometer & gyroscope for **activity tracking and fall detection**
- Real-time data preprocessing and filtering

### AI Health Advisory
- Powered by **Large Language Models (LLMs)**
- Generates:
  - Personalized health insights
  - Symptom interpretation
  - Preliminary health recommendations
- Designed as **supportive guidance**, not medical diagnosis

### Blockchain-Secured Records
- Blockchain-based verification of patient records
- Hashed health data ensures:
  - Immutability
  - Transparency
  - Tamper resistance
- Privacy-preserving data management

### Cross-Platform System
- Mobile application (Android / iOS)
- Web dashboard for visualization and record access
- Cloud backend for analytics and storage
