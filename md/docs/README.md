# BioTrack Documentation Hub

This folder centralizes operational and technical documentation for the BioTrack system.

## Contents

- `docs/SECURITY.md`
  - Security implementation summary and control mapping.
- `docs/THREAT_MODEL.md`
  - System-wide DFD/STRIDE-style threat model, OWASP mapping, and risk scoring matrix.
- `docs/AI_EVALUATION.md`
  - AI design goals, validation dataset, quantitative metrics, behavioral coverage, and explainability notes.
- `docs/API_REFERENCE.md`
  - Backend API endpoint reference grouped by module.
- `docs/DEPLOYMENT.md`
  - Deployment guide for backend and web services.
- `docs/TROUBLESHOOTING.md`
  - Common issues and direct fixes.
- `docs/MAINTENANCE.md`
  - Routine maintenance, backups, and operational checks.
